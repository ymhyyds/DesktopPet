DesktopPet 是一款支持 Live2D 模型、AI 对话、语音朗读、天气感知、桌面互动和个性化设置的 Windows 桌面宠物应用。

程序采用便携式发布，无需安装 Qt 或 Python。下载 Release 压缩包并完整解压后，即可直接运行。
